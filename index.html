File Quality Standard

Every File Is Tested Before It Goes Live

Every model in our shop goes through a strict quality review before publishing. We run each file through a manifold check in Meshmixer and Netfabb, followed by a real test print on both FDM and resin machines. Support structures are optimized to minimize post-processing, and every file is confirmed watertight and slicer-ready before it reaches your cart.

  • Verified manifold in Meshmixer & Netfabb
  • Test-printed on FDM (0.4 mm nozzle) before publishing
  • Resin-compatible version included where relevant
  • Pre-supported version available on select files

Common Questions

What file formats are included?
+

Each listing includes STL, OBJ, and FBX files in a single ZIP archive.

Can I use the files commercially?
+

Our standard license covers personal use and small-batch commercial printing (up to 50 units). For larger runs, contact us for a commercial license.

Are the files compatible with my printer?
+

Yes. Files are tested on FDM (Ender 3, Prusa MK4) and resin (Elegoo Mars) printers. Slicer-ready for Cura, PrusaSlicer, and Chitubox.

What if a file doesn't print correctly?
+

Contact us through Etsy. We'll troubleshoot with you and send a fixed file at no charge if the issue is on our end.

Do you offer custom 3D modeling?
+

For custom commissions, send us a message on Etsy with your project details. Pricing depends on complexity.

How do I download after purchase?
+

Etsy sends a download link immediately after payment confirmation. Files are also accessible anytime from your Etsy account under "Purchases".
